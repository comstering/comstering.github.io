# cowork 기록 문서 공통 규칙

- 기획(`cowork/prd`)·디자인(`cowork/design`)·개발(`cowork/develop`) 세션은 문서로 소통한다. 각 세션은 자기 폴더에만 쓴다. 다른 세션 질문에 대한 답은 자기 폴더에 쓰고, 질문 쪽 문서에는 번호만 링크한다.
- 합의(확정) 전 내용은 구현 기준이 아니다.
- PRD 기능 ID(F-PO-03 등), 문제 ID(P1 등), PR 번호, 디자인 문서 번호(`12번 E1`처럼)를 그대로 인용한다.
- 확인하지 못한 것은 "못 했다"고 적는다. 측정값에는 환경(로컬 서버, 브라우저, CI)을 같이 적는다.
- 저장소가 public이므로 비밀·연락처·내부 수치는 쓰지 않는다.
- 커밋·PR 시점은 [commit-and-pr.md](./commit-and-pr.md).

## 문서 고칠 때 함정

- **STATUS.md를 구간(`s.index(a)`~`s.index(b)`)으로 통째로 바꾸면 그 사이 절이 지워진다.** PR-13 때 "다음 작업"~"PR-13 동작" 사이의 PR 표·현재 상태·측정값 절이 사라졌고 PR #47 전까지 모르고 있었다. 치환 전에 구간 안에 있는 `## ` 제목을 출력해 보고, 바꾼 뒤에는 `grep -n "^## " STATUS.md`로 절 목록을 확인한다.
