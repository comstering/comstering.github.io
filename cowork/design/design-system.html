one list grammar

글·프로젝트·관련 글·검색 결과·타임라인 모두 같은 3단 구조. 한 번 익히면 모든 페이지를 같은 방식으로 훑는다.

1meta: 모노 12, mute (날짜, 분류, 기간, 회사)

2title: Pretendard 600, hover accent

3support: 설명 2줄, 성과 숫자, 태그나 스택

proof link (증명의 연결선)

성과 숫자 옆에는 근거로 가는 →를 둔다. About 역량 → 프로젝트 → 근거 글 → 저자 박스 → About으로 순환한다. 회사 성과와 개인 실습 글을 섞어 보이지 않는다. 개인 환경 글은 personal로 표기한다.

원칙과 금지

  1. 글이 주인공장식보다 읽기 쉬운 본문과 목록 스캔이 먼저
  2. 포인트 색은 하나, 아껴서accent는 링크·활성·포커스·주 CTA에만. warn은 경고 콜아웃에만
  3. 토큰만 쓴다hex, gray-*/sky-*, dark: 색 클래스 금지. 라이트/다크는 변수가 처리
  4. 증명의 연결선을 보이게성과 수치 옆에는 관련 글·프로젝트 링크. 개인 실습 글은 personal 표기
  5. 한 화면, 한 목적primary 버튼은 화면당 하나
  6. 리스트 문법 하나meta → title → support. 카드 그리드 대신 세로 리스트
