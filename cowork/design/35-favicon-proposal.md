# 35. 파비콘 디자인 제안

작성: 디자인 세션 · 2026-11-07
요청: 작성자(Chrome 탭에 뜨는 현재 파비콘을 다른 이미지로 교체)
시안: `site/favicon.html`(비교 보드), 원본 `favicon/*.svg`, 렌더 `favicon/png/*`(16·32·48·180px), 렌더 스크립트 `tools/render-favicons.mjs`

## 1. 결론

| 항목 | 내용 |
|---|---|
| 지금 | `src/app/favicon.ico`(16·32px 2종). **흰 바탕에 "Comstering's Dev Notes" 필기체**라 탭 크기(16px)에서 글씨를 읽을 수 없고, 어두운 사이트 아이덴티티(Terminal Graphite)와도 맞지 않는다 |
| 후보 | 5종 · A `>_` 꺾쇠+커서 · B `>_` 초록 바탕 · C `c_` · D `h_` · E `~/` |
| **추천** | **C `c_`.** 안전한 대안은 A |
| 공통 규칙 | 어두운 둥근 사각형(`canvas` `#0C0F0E`) + 글자 `fg` `#E6EDE9` + 커서 `accent` `#5BF29B`. 브라우저 탭 배경은 사이트 테마가 아니라 브라우저 테마(라이트/다크)를 따르므로 **어두운 사각형을 깔아** 어느 쪽에서도 보이게 한다. 획 굵기 3~3.6/32, 글자는 글리프 대신 도형(path)이라 폰트 의존이 없다 |

## 2. 비교 (16px 탭 기준, Playwright Chromium 렌더 + 라이트·다크 탭 모사)

| 안 | 모양 | 16px 가독성 | 아이덴티티 | 평가 |
|---|---|---|---|---|
| A | 흰 `>` + 초록 `_` | 가장 분명 | 프롬프트+커서 말투는 맞지만 터미널 앱 아이콘과 거의 같아 **구별이 약함**. 이름과 연결 없음 | 안전·무난 |
| B | 초록 바탕 + 어두운 `>_` | 탭 줄에서 가장 눈에 띔 | accent를 3% 이하로 아끼는 원칙과 결이 다름(면 전체가 초록). 터미널 앱 같음 | 홈 화면 아이콘용으로는 강함 |
| **C** | 흰 `c` + 초록 `_` | 좋음. 둥근 획이라 가장자리가 부드럽게 번짐 | **이름 + 로고 끝 커서**. 워드마크 `~/comstering_`의 끝(`c…_`)을 줄인 모양이라 사이트 이름이 곧 아이콘. 탭이 많아도 구별됨 | **추천** |
| D | 흰 `h` + 초록 `_` | 좋음 | 히어로 명령 `history`의 h. 명령이 바뀌면 의미 소실, 흰 `h.`가 마침표처럼도 보임 | 문구에 종속 |
| E | 흰 `~` + 초록 `/` | 읽히지만 물결이 가장 가늘고 흐림 | 로고 시작 `~/`와 직결. 이름·커서 요소 없음 | 의미는 좋으나 약함 |

**왜 C인가:** 파비콘의 일은 "탭이 여러 개일 때 이 사이트를 찾게 하는 것"이다. A는 읽기는 쉽지만 다른 개발 도구 탭(터미널, 로그 뷰어)과 구별되지 않고, B는 눈에 띄지만 사이트의 절제된 톤(커서 하나)과 다르다. C는 글자 하나라 16px에서도 읽히고, 이름(c)과 커서(_)가 있어 사이트 정체성이 그대로 줄어든 형태다. 히어로 문구가 바뀌어도 의미가 유지된다(D와 차이).

## 3. 한계·주의

- 16px 판정은 **브라우저가 SVG를 그린 결과**(Chromium)다. 실제 Chrome 탭 렌더, Safari·Firefox, Windows 작업 표시줄, 북마크 막대는 확인하지 못했다.
- 후보는 아직 **데스크톱 탭·북마크용**이다. 확정하면 아래 패키지를 만든다.
- 어두운 사각형 + 1px `line` 테두리는 라이트 탭에서 사각형 윤곽이 또렷하고 다크 탭에서는 배경과 가까워 자연스럽다(보드의 "tab" 절 참고).

## 4. 확정되면 개발에 넘기는 것

Next.js App Router 파일 규약(`src/app/`)에 맞춘 4개 파일을 디자인이 만들어 `cowork/design/favicon/final/`에 둔다.

| 파일 | 용도 | 비고 |
|---|---|---|
| `icon.svg` | 현대 브라우저 탭(벡터) | 지금 SVG 그대로 |
| `favicon.ico` | 구형·북마크·일부 도구 | 16·32·48px 포함 |
| `apple-icon.png` | iOS 홈 화면 | 180×180, **둥근 모서리·테두리 없는 꽉 찬 정사각형**(iOS가 마스크를 씌움) |
| `icon-512.png` | 선택(PWA·카카오 등) | 필요할 때만 |

개발은 `src/app/favicon.ico`를 교체하고 `icon.svg`·`apple-icon.png`를 추가한다(별도 `<link>` 불필요). 교체 후 캐시 때문에 탭 아이콘이 한동안 이전 것으로 보일 수 있다(브라우저 파비콘 캐시, 강력 새로고침으로 확인).

## 6. 재현

```bash
python3 -m http.server 4175 &                              # 저장소 루트에서
node cowork/design/tools/render-favicons.mjs               # favicon/*.svg → favicon/png/*-{16,32,48,180}.png

```
