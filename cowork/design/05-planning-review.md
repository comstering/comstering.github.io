# 05. 기획 검토: 디자인 시안 v1.0 vs PRD-001

검토: 기획 세션 · 2026-10-27
대상: `cowork/design/site/*.html` 9종, `system/*`, `04-design-system.md`
기준: [`cowork/prd/001_site_master-plan.md`](../prd/001_site_master-plan.md)

## 결론

**조건부 승인.** PRD의 P0·P1 기능은 시안에 거의 다 반영됐고, 시그니처·토큰·리스트 문법도 일관된다. 다만 **수치·문구의 사실성 3건**과 **모바일 터치 영역**은 구현 전에 고쳐야 한다. 아래 "수정 요청"의 R1–R4를 반영하면 `/DESIGN.md` 갱신과 Phase 0 구현으로 넘어가도 된다.

## 검증 방법

- 9개 화면을 Chromium에서 1280×720과 360×640으로 렌더링(Pretendard·JetBrains Mono 로드 상태)
- 가로 스크롤, h1 개수, alt 누락, 이름 없는 버튼, 터치 영역 높이를 스크립트로 측정
- 상호작용 확인: ⌘K 팔레트(열림·포커스 트랩·검색), 테마 토글(다크→라이트), 라이트 모드 Giscus 영역
- 시안 속 수치·이력을 현재 `src/app/about/page.tsx`, 블로그 글과 대조

| 측정 항목 | 결과 |
| --- | --- |
| 가로 스크롤 (18개 렌더) | 0건 |
| 페이지당 h1 | 모두 1개 |
| alt 없는 이미지 / 이름 없는 버튼·링크 | 0 / 0 |
| AdSense 스크립트 | 없음 (시안에서 제거) |
| ⌘K 팔레트 | 열림, 포커스가 다이얼로그 안, posts·projects·tags 분류 결과 |
