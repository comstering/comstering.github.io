## 결론

**D-6~D-10 시안을 채택한다.** 히어로 안(Q1)만 작성자 선택을 기다린다. 나머지 Q2~Q5는 디자인 의견대로 정했고, Q6은 작성자가 고친다. 25번에서 디자인이 스스로 정한 두 가지(앵커 도착 강조 없앰, 기간 열 제거로 밀도 V3)와 `resume.pdf` 5쪽도 동의하고 PRD에 적었다.

| # | 질문 | 답 | 시안 수정 |
|---|---|---|---|
| Q1 | 히어로 안·문구 | **작성자 선택 대기.** 기획 추천도 **2b + `$ git log --oneline` / "배운 것과 만든 것, 그 사이의 기록"**. 정해지면 PRD-004 5.2에 확정값을 적고 알린다 | 확정 후 비교 도구 제거 |
| Q2 | 모바일 사이드바 위치 | **③ 지금대로(글 목록 아래).** 모바일은 검색 유입이 많고 첫 화면은 글로 채운다. 시리즈는 글 상세의 시리즈 내비가 이미 맡는다. 다시 볼 조건: 인기글 데이터가 쌓여 효과가 확인될 때, 또는 페이지네이션(F-HM-05)으로 목록이 짧아질 때 | 없음 |
| Q3 | 검색 `# 소제목` 보조 줄 | **쓴다.** 소제목에서만 맞은 글이 왜 나왔는지 알려 준다. 제목·설명·태그에서 맞은 글에는 붙이지 않는다 | 없음 |
| Q4 | 사이드바 태그 글 수 | **표시한다.** 정렬 근거가 보이고, 홈 카테고리 칩(`infra 11`)과 표기가 같아진다 | 없음 |
| Q5 | 검색 버튼 이름 `검색 (search)` | **동의.** 보이는 글자를 이름에 포함하는 규칙(NF-03)이 우선이다. 24번의 `검색`은 정정한다 | 없음 |
| Q6 | 글 제목 오타 `Kapenter` | **작성자가 고친다.** 제목만 `Karpenter`로, 파일명(URL)은 그대로. 고치면 시안 인덱스는 생성기로 다시 만든다 | 작성자 수정 후 인덱스 재생성 |
