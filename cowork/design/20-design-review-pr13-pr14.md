## 1. PR-13 관련 글

### 데이터: PRD 규칙과 일치

PRD F-PO-06 규칙(태그 교집합 수가 점수, 같으면 최신순, 같은 시리즈·이전/다음·draft 제외, 점수 0 제외, 최대 3편)을 **구현 코드를 보지 않고 글 frontmatter에서 독립 계산**해 빌드 화면과 비교했다.

| 항목 | 결과 |
|---|---|
| 14편 전부 | 관련 글 목록이 독립 계산 결과와 **정확히 같다**(순서 포함) |
| 0편인 글 3편 | `2025-retrospective-2026-resolutions`, `first-contribute-opensource`, `implement-my-site`는 섹션이 그려지지 않는다 |
| 중복(수용 기준) | 같은 글이 시리즈 박스·이전/다음·관련 글에 두 번 나오는 경우 0건 |
| 위치 | 이전/다음 아래, 댓글 위. 글 상세 제목 순서가 `… > related > comments`(1280px·360px) |

### 형식: 시안과 같다

| 항목 | 시안 | 구현 | |
|---|---|---|---|
| 항목 제목 | Pretendard 18px / 600 | 같음 | ✓ |
| 설명 | 15px / 400, 1줄 | 같음, 1줄 | ✓ |
| 태그·이미지 | 없음 | 없음 | ✓ |
| 항목 간격(PC) | 약 116px | 약 115px | ✓ |

(처음 항목 높이를 117px 대 81px로 읽었으나, `article`과 링크 래퍼를 서로 다르게 잰 측정 오류였다. 화면에서 간격은 같다.)

### F1: 목록·관련 글 링크 이름이 너무 길다 (낮음, 권장)

| | 시안 | 구현 |
|---|---|---|
| 링크 범위 | 제목 `h3` 안의 `<a>`만. `::before`로 행 전체를 클릭 영역으로 확장 | `<a>`가 `<article>` 전체를 감쌈 |
| 링크 이름 | 제목만 (예: 40자) | 날짜·카테고리·시리즈·제목·설명 전부 (**관련 글 138자, 홈 목록 136~176자**) |

- 시안의 `.post-item__title a::before { inset: 0 }` 패턴은 행 전체를 누르게 하면서 링크 이름을 제목으로 짧게 유지하려는 것이었다(04번 "전체 행이 링크").
- 영향: 스크린리더 링크 목록, 음성 제어("제목 클릭"). Lighthouse 감사에는 걸리지 않는다. 시각적 차이는 없다.
- `PostListItem`이 홈·태그·관련 글에 공용이라 한 곳을 고치면 모두 바뀐다.

### F2: 섹션 제목 라벨 굵기 (낮음)

시안 `.sec-head__label`은 굵기 700(`//`는 mute)이고 구현은 400이다(`// related`, `// comments`에서 확인). 홈·About의 섹션 제목은 이번에 재지 않았다. 한 줄 차이라 `SectionHead`에서 맞추면 된다.

## 2. PR-14 이미지 확대 (수정 요청 없음)

12번 E3와 PRD PR-14의 확대 요구사항을 실제 브라우저에서 확인했다(글 상세 1280px).

| 항목 | 결과 |
|---|---|
| 확대 대상 판정 | 본문 이미지 60장 중 59장이 확대 대상. 변환본 폭 > 720px 규칙과 **불일치 0**. 대상은 `role="button"`, `tabindex="0"`, `cursor: zoom-in`, `alt` 있음 |
| 열기 | 이미지에 포커스 후 Enter로 열림. `<dialog>`가 모달(`:modal`) |
| 포커스 | 열면 닫기 버튼으로 이동. 닫기 버튼 **44×44** |
| 닫기 | Esc, 바깥 클릭, 닫기 버튼 모두 닫힘. **닫으면 눌렀던 이미지로 포커스 복귀** |
| 배경 | Tab을 6번 눌러도 포커스가 페이지 링크로 가지 않고 `body`와 dialog 사이만 오간다(배경 inert). dialog가 화면 전체를 덮음 |
| 모션 | `prefers-reduced-motion: reduce`에서 dialog·이미지 애니메이션 없음 |
| 화면 | 1280px에서 이미지가 약 1232px 폭으로 보이고 배경이 어두워진다. 닫기 버튼은 오른쪽 위 |
