## 배경: 작성자 결정 (2026-11-02)

| 항목 | 결정 |
| --- | --- |
| 역할 분리 | **홈 = 블로그, About = 경력·이력서·기술.** 홈에 이름·직함·기술 태그·성과·경력 링크를 두지 않는다 |
| About ↔ 블로그 | **서로 링크하지 않는다.** 블로그는 개인 학습·프로젝트 기록이라 회사 경력과 연결하면 회사 일처럼 읽힌다. 관련 글 목록, `personal/work` 표시, 저자 박스 `관련 경력 →`, 자격증 후기 글 링크 모두 없음 |
| About 경력 | 접지 않고 전부 펼친다. 채용 담당자는 내용을 읽으러 온다 |
| what i do | 삭제 |
| 이력서 | `/resume` 페이지 없음. About을 인쇄 스타일로 PDF로 만들어 About에서 내려받는다. 축약 없음 |
| 검색 | **헤더 검색 버튼 + `⌘K` 팔레트(지금 시안)를 이번 Phase에 넣는다.** 홈 글 목록 위 검색창은 없앤다 |
