## 5. 겪은 함정 (디자인 쪽)

- **같은 선택자의 규칙은 소스 순서가 이긴다.** 인쇄 규칙을 앞에 두면 뒤의 화면 규칙에 덮인다. 쪽 수가 갑자기 늘면 내용보다 규칙 순서를 먼저 본다. `.claude/rules/css.md`에도 있다.
- **생성 시안은 원본이 바뀌면 깨진다.** `tools/build-phase2-mockups.py`는 About 데이터를 `src/app/about/page.tsx`에서 읽는데 개발 PR-18·19가 `content/*.yaml`로 옮겨 **지금은 실행되지 않는다.** About·홈 시안은 확정·구현돼 다시 만들 일이 거의 없다. 필요하면 생성기가 `content/experience.yaml`·`profile.yaml`을 읽게 고친다.
- **CSS 일괄 치환은 한 줄 `@media … { 규칙 }`를 반쪽만 지울 수 있다.** 중괄호가 깨진 적이 있다(576/575). 치환 뒤 `{`·`}` 개수를 세고 이전 Git 버전과 대조한다.
- **눈으로 본 정렬은 틀릴 수 있다.** apple-icon이 한쪽으로 쏠렸다고 판단했다가 픽셀로 재니 18/22px이었다. 측정해서 20/20으로 맞췄다. 후보를 평가하는 글은 렌더를 본 뒤에 쓴다.
- **측정 환경을 같이 적는다.** 실제 Chrome 창은 폭 406px 아래로 줄지 않아 360px은 Playwright Chromium으로 잰다. 36번 검토에서 실제 Chrome 확인을 건너뛰어 지적받았다. 화면에 보이는 것은 실제 Chrome으로 확인한다.
- `html { scroll-padding-top }`이 앵커 위치를 맡는다. 항목에 `scroll-margin-top`을 또 주면 두 번 더해진다.
- 백그라운드 세션은 worktree 격리 때문에 Write/Edit 전에 worktree에 들어가야 하고, 훅이 `git`을 `rtk git`으로 바꾸면 격리 가드가 거부해 `/usr/bin/git`을 직접 쓴다.

## 6. 일하는 방식에서 굳어진 것

- 규칙은 `.claude/rules/`로 옮겨 Claude Code가 자동으로 읽는다(2026-11-08). 경로 지정 규칙은 Read·Write·Edit로 맞는 파일을 열 때 불려온다.
- **다른 세션에 문서를 넘기는 시점마다 묻지 않고 커밋 → push → PR**을 연다(작성자 결정 11-08). 개발 세션이 같은 작업 폴더를 쓰면 별도 worktree에서 만든다.
- 질문·답은 `NN-주제.md`로 쓰고 `README.md`에 한 줄 넣는다. 다른 세션 폴더에는 번호만 링크한다.
- 디자인은 `/DESIGN.md`와 `src/`를 고치지 않는다.
